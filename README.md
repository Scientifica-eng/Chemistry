# Chemistry — مختبر المحاليل

نسخة تجريبية لموقع تعليمي تفاعلي باللغة العربية (RTL) موجّه للمخبريين. يشرح تحضير المحاليل ذات التراكيز الكتلية والمولية انطلاقًا من مادة صلبة، واستخراج تركيز كاشف سائل تجاري من بياناته ثم تخفيفه.

## تشغيل الموقع

الموقع ثابت ولا يحتاج إلى تثبيت حزم أو خادم تطبيقات:

1. افتح index.html مباشرة في متصفح حديث.
2. أو شغّل خادم ملفات ثابتة من جذر المستودع، مثل الأمر: python -m http.server 8000، ثم افتح http://localhost:8000.
3. للنشر بواسطة GitHub Pages، اختر الفرع والمجلد اللذين يحتويان index.html من Settings → Pages. ملفات HTML وCSS وJavaScript في الجذر؛ لا توجد عملية بناء.

يستخدم الموقع خطين اختياريين من Google Fonts لتحسين العرض؛ عند تعذّر الاتصال بهما تُستخدم الخطوط الاحتياطية المحلية.

## محتوى النسخة التجريبية

- أهداف تعليمية وكفايات قابلة للتأشير وخريطة تنقل داخل الدرس.
- شرح التركيز الكتلي والمولي وعلاقة التخفيف، مع مثال محلول خطوة بخطوة.
- بروتوكول تعليمي لتحضير محلول من مادة صلبة، ومسار لحساب تركيز كاشف سائل وتخفيفه.
- ثلاث حاسبات تفاعلية: كتلة الصلب مع تصحيح النقاوة، تركيز الكاشف من الكثافة والنسبة الكتلية، وحجم المأخوذ للتخفيف.
- 28 تمرينًا في المفاهيم والحسابات والإجراءات والسلامة، مع تصحيح فوري، وتلميحات، وحل مفسّر، وإعادة محاولة، ورصيد إتقان.
- مظهر داكن اختياري، وتصميم متجاوب، وتسميات مناسبة للتنقل بلوحة المفاتيح.

## حدود الاستخدام والسلامة

هذا موقع تعليمي ولا يحل محل إجراء التشغيل القياسي (SOP)، أو بطاقة بيانات السلامة (SDS)، أو إشراف المختص. مثال حمض الهيدروكلوريك المركز حسابي وتعليمي، وليس تعليمات مستقلة للتعامل معه. يُنفّذ العمل الحقيقي بعد التحقق من هوية الكاشف وبيانات المورد ومعدات الوقاية والتهوية والأدوات المعتمدة. القيم المحسوبة من الكثافة والنسبة الكتلية تقديرية إذا كانت بيانات المصدر أو درجة الحرارة غير مؤكدة، وقد يلزم توحيد التركيز تحليليًا.

## الملفات

- index.html — الهيكل والمحتوى العربي.
- styles.css — التصميم المتجاوب ودعم المظهر الداكن.
- app.js — الحاسبات، ومسار التحضير، والتدريب والتقويم.
- docs/lesson-design.md — التصميم البيداغوجي وتسلسل التعلم.
- docs/verification-checklist.md — قائمة تحقق يدوية قبل النشر.

## التحقق قبل النشر

راجع قائمة docs/verification-checklist.md، واختبر الموقع في متصفح مكتبي وهاتف، وتحقق من الحسابات بقيم مستقلة قبل استخدام المحتوى في تكوين مخبري رسمي.
