# قائمة تحقق قبل النشر

## العرض والوصول
- [ ] فتح index.html مباشرة دون أخطاء في تحميل الصفحة.
- [ ] التحقق من RTL وترتيب النصوص العربية في شاشة مكتبية وهاتف.
- [ ] تجربة الروابط الداخلية وخريطة الدرس والتنقل بين مساري التحضير.
- [ ] تجربة المظهر الداكن ثم العودة إلى الفاتح.
- [ ] التنقل بلوحة المفاتيح وحدها والتحقق من مؤشر التركيز والتسميات.

## الحاسبات
- [ ] حاسبة الصلب: C = 0.100 mol/L، وV = 250 mL، وM = 58.44 g/mol، ونقاوة 100% → m ≈ 1.461 g.
- [ ] حاسبة الصلب: cₘ = 5 g/L، وV = 250 mL، ونقاوة 100% → m = 1.25 g.
- [ ] تصحيح النقاوة: إذا كانت النقاوة 80%، كتلة الوزن تساوي الكتلة النقية المطلوبة ÷ 0.80.
- [ ] حاسبة الكاشف: ρ = 1.18 g/mL، وw = 37%، وM = 36.46 g/mol → cₘ ≈ 436.6 g/L وC ≈ 11.97 mol/L.
- [ ] حاسبة التخفيف: C₁ = 1.00 mol/L، وC₂ = 0.100 mol/L، وV₂ = 250 mL → V₁ = 25.0 mL.
- [ ] رفض القيم غير الموجبة، ورفض النقاوة أو النسبة الكتلية فوق 100%، ورفض تخفيف ينتج تركيزًا أعلى من تركيز المحلول الأم.

## التمارين
- [ ] جرّب سؤال اختيار من متعدد بإجابة صحيحة وبإجابة خاطئة.
- [ ] جرّب سؤالًا رقميًا باستخدام النقطة ثم الفاصلة العشرية.
- [ ] تأكد أن المحاولة الصحيحة تمنح نقطة واحدة فقط.
- [ ] تأكد أن كشف التصحيح لا يمنح نقطة، وأن التلميح لا يكشف الجواب.
- [ ] جرّب المرشحات والصفحات وإعادة جميع التمارين.
- [ ] تأكد من تحديث المؤشرات عند بلوغ 5 و14 و28 إجابة صحيحة.

## مراجعة علمية وتدريبية
- [ ] مطابقة الصيغ والوحدات مع المرجع أو الإجراء المعتمد لدى المؤسسة.
- [ ] مطابقة بيانات أي كاشف حقيقي مع ملصقه وشهادة التحليل وSDS.
- [ ] مراجعة الصياغة العربية مع المدرّب أو المختص بالمخبر.
- [ ] عدم استخدام مثال HCl المركز لتوجيه تنفيذ عملي مستقل؛ يُطبّق SOP وتعليمات السلامة المحلية.
- [ ] عند الحاجة إلى تركيز مضبوط بدقة، تضمين طريقة توحيد أو تحقق تحليلي مناسبة للعملية.

هذه قائمة اختبار يدوي مقترحة؛ لا تدّعي النسخة الحالية أنها اجتازت اختبارات آلية شاملة أو تحققًا ميدانيًا.
